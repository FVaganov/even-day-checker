Workflow (Рабочий процесс) 
Это автоматизированный процесс, который выполняется при определенных событиях (например, push, pull request).
Определяется в YAML-файле в папке .github/workflows.
Может содержать один или несколько Jobs.

Job (Задача)
Это набор Steps, которые выполняются на одном Runner.
Jobs могут выполняться последовательно или параллельно (зависит от конфигурации).
Пример: build, test, deploy.

Step (Шаг)
Отдельное задание внутри Job.
Может быть командой shell (run) или Action.
Пример: установка зависимостей, запуск тестов.

Action (Действие)
Это отдельная, переиспользуемая задача, которая может быть частью Step.
Может быть написана вами или взята из GitHub Marketplace.
Пример: actions/checkout (для загрузки кода).

Event (Событие)
Действие, которое запускает Workflow (например, push, pull_request, schedule).
Можно настраивать фильтры (например, только для ветки main).

Runner (Исполнитель)
Это сервер (или контейнер), который выполняет Jobs.
Может быть GitHub-hosted (предоставляется GitHub) или self-hosted (ваш собственный сервер).
GitHub предоставляет runners с ОС Ubuntu, Windows, macOS.
